## Detailed Schema Field Specifications

### 1. Settings (`SettingsSchema`)

Location: `~/.gemini/antigravity-cli/settings.json`

| Field | Type | Default | Description |
|---|---|---|---|
| `toolPermission` | Enum | `"request-review"` | `request-review`, `proceed-in-sandbox`, `always-proceed`, `strict` |
| `artifactReviewPolicy` | Enum | `"asks-for-review"` | `asks-for-review`, `agent-decides`, `always-proceed` |
| `enableTerminalSandbox` | boolean | `false` | Run terminal commands inside isolated sandbox environment. |
| `allowNonWorkspaceAccess` | boolean | `false` | Allow file read/write operations outside active workspace root. |
| `trustedWorkspaces` | array[string] | `[]` | Whitelist of trusted local repository directory paths. |
| `colorScheme` | Enum | `"terminal"` | Color theme: `light`, `solarized light`, `dark`, `solarized dark`, `tokyo night`, `terminal` |
| `altScreenMode` | Enum | `"default"` | TUI alternate screen usage: `default`, `always`, `never` |
| `notifications` | boolean | `false` | Enable OS desktop notifications. |
| `showTips` | boolean | `true` | Show usage tips in prompt UI. |
| `editor` | string | `"auto"` | Preferred external text editor binary or command. |
| `editorMode` | Enum | `"default"` | Navigation mode: `default`, `vim` |
| `verbosity` | Enum | `"high"` | Log output verbosity: `high`, `low` |
| `model` | string | Optional | Persisted default model selection string (e.g. `Gemini 3.5 Flash (Low)`). |

### 2. Plugin Manifest (`PluginManifestSchema`)

Location: `plugins/<plugin-name>/plugin.json`

| Field | Type | Default | Description |
|---|---|---|---|
| `$schema` | string | `https://antigravity.google/schemas/v1/plugin.json` | JSON Schema URI |
| `name` | string | Folder name | Unique plugin identifier |
| `version` | string | `"1.0.0"` | Semantic version string |
| `description` | string | Optional | Human-readable summary of plugin capabilities |
| `dependencies` | array[string] | `[]` | List of required dependency plugins |

### 3. Agent Frontmatter (`AgentFrontmatterSchema`)

Location: `.agents/agents/<name>.md` or `~/.gemini/config/agents/<name>.md`

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | string | **Required** | Unique agent identifier (lowercase, hyphens) |
| `description` | string | **Required** | Planner delegation description |
| `tools` | array[string] | `[]` | List of permitted tool names |
| `mainAgent` | boolean | `true` | Selectable as primary agent in chat |
| `subagent` | boolean | `true` | Invocable via `invoke_subagent` |
| `model` | string | `"inherit"` | Model tier: `inherit`, `flash`, `pro`, `flash_lite` |
| `commandExecutionPolicy` | Enum | `"sandbox"` | Execution safety: `off`, `auto`, `eager`, `sandbox` |

Location: `~/.gemini/antigravity-cli/brain/<id>/.system_generated/logs/transcript.jsonl`

|---|---|---|---|

| `source` | Enum | Optional | Step origin: `USER_EXPLICIT`, `SYSTEM`, `MODEL`, `SUBAGENT` |
| `type` | Enum / string | **Required** | Step type: `USER_INPUT`, `PLANNER_RESPONSE`, `TOOL_CALL`, `CHECKPOINT`, `ERROR_MESSAGE` |
| `status` | Enum | `"DONE"` | Lifecycle status: `DONE`, `RUNNING`, `ERROR`, `ACTIVE` |
| `content` | string | Optional | Step payload text, prompt, or JSON output |
| `tool_calls` | array[object] | `[]` | Tool calls executed on step (`[{name, args}]`) |
